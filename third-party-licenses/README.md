# Preserved third-party license texts

See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for distribution boundaries, applicable licenses and unresolved provenance. [manifest.json](manifest.json) records each installed component/version, upstream source, license, original package-relative evidence path and SHA-256 of each copied text. Files in `texts/` are verbatim license/NOTICE contents or verbatim license sections from package README files. Version-verified upstream equivalents are identified explicitly.

These files do not claim ownership of third-party material or grant permission for copied vendor research/assets. Preserve applicable notices with the components when distributing source or release artifacts.
