# Durable reports and optional interaction adapters

Migration 018 adds isolated read jobs and one-use selection handles. Existing write jobs and journals retain their behavior. Report inputs and results use independently purpose-bound encrypted envelopes. Four pending reports per actor, three restart attempts, a 30-second renewable lease, 120-second execution deadline, 100 KB result limit, and 24-hour retention bound this first implementation. Lease fences prevent stale workers from saving results. Cancellation prevents further guarded reads; it does not claim an already in-flight HTTP read was undone. Poll/status/result retain ordinary tool access.

A report is a bounded observation, not an atomic snapshot. The executor requests one page per section/site and retains provider continuations and completeness. This version does not silently resume a whole fleet scan after restart; a recovered read job reruns its bounded observation with fresh authorization. Expired data is inaccessible immediately and physically deleted in bounded maintenance batches. PostgreSQL storage and encryption configuration are required for production durability; memory stores are fixture-only.

Selection MRTR uses the installed SDK inputRequired builder. Encrypted state binds employee, tenant, operation, input fingerprint, policy/mapping versions, five-minute expiry, and reviewed candidate IDs. A persistent one-use nonce prevents replay; fresh native authorization occurs before accepting a selection. Decline/cancel consumes the continuation. Unsupported hosts receive ordinary authorized candidates. This handles read selection only, not business-write approval.

The installed @modelcontextprotocol/server 2.0.0 cannot serve modern tasks/get through even an explicit custom handler: the modern era registry returns HTTP 404 / JSON-RPC -32601. The regression spike captures this. Native Tasks remains disabled; exported legacy Task types are not proof of modern extension support. The isolated wire adapter follows the [released Tasks extension](https://tasks.extensions.modelcontextprotocol.io/specification/2026-07-28/tasks), including request capability checks and representing tool failures as completed tasks containing isError. It is not registered into production transport. An upgrade or separately reviewed extension transport remains necessary before a host pilot.

Validation: memory and PGlite stores, encrypted payloads, quotas/deduplication, lease loss/renewal/fencing, cancellation/restart, expiry/purge, actor/company/section revocation, bounded noncooperative reads, runtime schemas, and actual SDK MRTR/Tasks behavior. Real ChatGPT/Codex interaction qualification remains pending.
